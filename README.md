### What I'm Building

</div>

```
Project Lyra is an autonomous concentrated liquidity management system on Solana.

10 named AI agents, each specialized for a specific token.
Each with its own optimized parameters, role, and personality.
Each making independent entry, rebalance, and exit decisions.

Live on Meteora DLMM. Expanding to Orca Whirlpools and Raydium CLMM.

The tech is serious. The UX just happens to have pink hair.
```

## The Agent Swarm

<div align="center">

<img src="./assets/agents.svg" alt="Agent Roster" width="100%">

</div>

<br/>

Each agent operates independently with:
- **Individually optimized parameters** from walk-forward backtesting across thousands of configurations
- **Its own persona and voice** so you can tell at a glance who did what and why
- **Adaptive range management** tuned to the volatility profile of its assigned token
- **IL circuit breakers** that trigger automatic protective exits

Performance numbers coming soon. We don't publish numbers without publishing the cost model.
